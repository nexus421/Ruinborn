# Ruinborn

A base building and strategy game for a private server with up to 50 friends. It is inspired by a well-known mobile
zombie strategy game. All progress is earned by playing. There are no in-app purchases.

Build your base, research, train troops and level heroes. Fight zombies and nests on a shared world map, gather
resources, attack other players and join alliances for rallies, help and chat.

## Status

Version 1 is implemented and playable. The desktop client was developed and tested on Linux. The Android app has only
been tested in the emulator so far. Balancing still needs real play data.

The game is in German only for now. Code, comments and documentation are in English. The
[game concept](Ruinborn%20%E2%80%93%20Spielkonzept%20v1.md) is in German.

## Tech stack

Kotlin Multiplatform, libGDX with KTX, Ktor (server and client), SQLite with Exposed. The game rules live in
`commonMain` and are shared by server and clients.

| Module | Content |
| --- | --- |
| `shared` | game rules, formulas, combat, DTOs, balance (`shared/balance/balance.json`) |
| `client` | HTTP and WebSocket client, game state |
| `core` | libGDX client: screens, HUD, dialogs, isometric rendering |
| `lwjgl3` | desktop launcher |
| `android` | Android launcher (only built if an Android SDK is found) |
| `server` | Ktor server, single-writer engine, SQLite, jobs, admin commands, balancing simulation |
| `tools` | texture packing and bitmap fonts |

## Getting started

Requirements:

- JDK 17 or newer to run Gradle. The toolchain JDK (Amazon Corretto 25) is downloaded automatically if missing.
- For the Android app only: Android SDK with platform 37.
- For regenerating the graphics only: Python 3 with Pillow, NumPy and SciPy.

```bash
./gradlew build                                           # build and run all tests
./gradlew :server:run --args="--config dev/config.json"   # local server on port 8080
./gradlew :lwjgl3:run                                     # desktop client
```

Register with the invite code `dev`. Registering as `admin` gives admin rights.

Android app in the emulator:

```bash
./gradlew :android:installDebug -Pruinborn.androidServerUrl=http://10.0.2.2:8080
```

Desktop launch options, deployment and admin commands are described in [docs/OPERATIONS.md](docs/OPERATIONS.md).

## Tests

`./gradlew build` runs 111 tests. The server tests use the real engine with a temporary SQLite file and a controllable
clock. `./gradlew :server:runSim` runs a balancing simulation over 60 days and writes `sim-result.csv`.

## Graphics and fonts

The isometric placeholder sprites are generated by the Python scripts in `tools/sprites`.

```bash
python3 tools/sprites/generate.py   # frames to assets-raw/sprites
./gradlew :tools:packTextures       # atlas to assets/atlas
./gradlew :tools:generateFonts      # bitmap fonts to assets/fonts
```

The font is Noto Sans under the SIL Open Font License ([assets-raw/fonts/OFL.txt](assets-raw/fonts/OFL.txt)).
